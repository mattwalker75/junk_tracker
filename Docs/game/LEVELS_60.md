## Run mode: Normal or Hardcore (Matt, Nov 11 2026: option C)
- Picked when a run starts (Start Run screen), shown on the map/HUD as a badge.
- **Normal** — at 0 hearts you are *knocked back* to the **first level of the world you were in** (a checkpoint) with 3 hearts. The run and its score carry on; the monsters you beat in that world must be beaten again. A knock-back costs −250 points. A Normal run ends when you beat level 60 (or start a new run yourself); its score is live on the Hall of Heroes the whole time.
- **Hardcore** — at 0 hearts the run is over and the next run starts at **level 1**. Hardcore runs earn **×1.25 on all points** and get a skull badge in the Hall of Heroes (separate Hardcore leaderboard tab).
- You may switch a Hardcore run to Normal at any time (it loses the ×1.25 from then on and the skull); you can't switch Normal to Hardcore mid-run.
- Sample state: Run #3 is **Normal**.

## Splurge time (Matt, Nov 11 2026)
- Splurges get an OPTIONAL time, in game mode AND in the regular app's Log a splurge sheet (like activities have; when building, change the real LogSheet.tsx too — today it has no time: "the day is enough").
- **No time given = assume the worst** for time-based abilities: Midnight Snacker (after 9 PM ×2) treats it as after 9 PM; Hash Hound (before 11 AM ×2) treats it as before 11 AM; Fondue Fiend (within 3 h of another ×2) treats it as within 3 h of any other splurge that day.

## Same fields in both modes (Matt, Nov 11 2026)
- The Log a splurge and Log activity sheets have the SAME fields, order, options and labels in the dashboard and in game mode. Game mode only re-skins them (game palette, chunky buttons) and adds the live damage / heal panel. When building: one form component, two skins — never two different forms.
