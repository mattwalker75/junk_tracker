# Craving Crusher for Android

Not started yet. This is where the Android version goes. See `../README.md` for what a port starts from.

- The app name is **Craving Crusher**.
- The Play Store icon is `web/public/icon-512.png`. The launcher wants an *adaptive icon*: a background
  layer and a foreground layer, 108 dp square with the picture inside the middle 66 dp, plus a one-colour
  version for Android 13's themed icons. `Docs/icon/README.md` says how to make them from `Docs/icon/icon.svg`.
